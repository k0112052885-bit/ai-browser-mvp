AI Browser 다운로드

Mac에서 처음 실행할 때 보안 안내가 뜰 수 있습니다. 아래 순서대로 설치하면 실행할 수 있습니다.

  1. 1아래 버튼으로 DMG 파일을 다운로드합니다.
  2. 2DMG를 열고 AI Browser.app을 Applications 폴더로 드래그합니다.
  3. 3터미널 열기 버튼을 누릅니다.
  4. 4실행 코드 복사 버튼을 누른 뒤 터미널에 붙여넣고 Enter를 누릅니다.
AI Browser v1.0.2 다운로드 터미널 열기
xattr -cr /Applications/AI\ Browser.app && open /Applications/AI\ Browser.app

참고: 현재 버전은 Apple 개발자 서명 전 테스트 배포용입니다. 터미널 명령은 Mac 보안 격리 속성을 제거하고 앱을 여는 명령입니다.

실행 코드가 복사되었습니다.
